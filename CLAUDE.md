## System Architecture (Read This First)

Quant Radar is a **6-stage sequential pipeline** for US equity swing trading signals.
No stage is skipped. Each stage outputs to the next. All outputs are static files
committed to GitHub Pages — there is no backend server.

```
Universe (738 tickers)
  → Radar Scanner       [screener.py + screen_score.py]
  → Sniper Validator    [bulk_sniper.py + backtest_engine.py]
  → Portfolio Planner   [porto_builder.py]
  → Tracker Matrix      [tracking_helper.py]
  → Alpha Executor      [run_execution.py + build_execution_dashboard.py]
```

**Daily pipeline entry point:** `us_market/pipeline/run_daily.py`

## Module Map

### Configuration
```
us_market/config/
  settings.py           ← ALL parameter constants live here (windows, thresholds, weights)
  ticker_universe.csv   ← Source of truth for 738 tickers
  ticker_universe.py    ← Script to rebuild ticker_universe.csv
```
> **Parameter tuning target:** `settings.py` is the primary file for any experiment
> involving lookback windows, percentile thresholds, score weights, or hold periods.

### Core Engine
```
us_market/engine/
  screen_score.py       ← Radar score formula: ΔP14 × VOL_SURGE × RANGE_POS_325
                           + rolling 95th percentile threshold per ticker
                           + DISTANCE_% and Z_SCORE computation
  backtest_engine.py    ← Event-based backtest: signal days → forward returns (5D/10D/20D)
                           + Edge score (tanh-normalized) + Quality score (Sample/Cluster/Stability)
                           + Sniper Score formula + Conviction tier assignment
```
> **Signal quality experiments happen here.** Changing the radar formula or
> scoring weights requires editing these two files.

### Analysis Scripts
```
us_market/analysis/
  screener.py           ← Runs full universe scan → produces radar output CSV
  bulk_sniper.py        ← Runs Sniper backtest on all radar-positive candidates
  single_sniper.py      ← Runs Sniper backtest on a single ticker (for debugging)
```

### Dashboard Builders (HTML Output Generators)

  universe_builder.py   ← Builds universe/index.html (Universe page)

## Key Formulas (Quick Reference)

**Radar Score:**
```
RADAR_SCORE = ΔP14 × (V / SMA_V_20) × ((P - L325) / (H325 - L325))
DISTANCE_% = (RADAR_SCORE - THRESHOLD) / THRESHOLD × 100
Threshold = rolling 95th percentile of 3-year RADAR_SCORE history per ticker
```

**Sniper Score:**
```
EDGE_RAW = mean(E5, E10, E20)  where En = AVG_n × WR_n
EDGE_NORM = tanh(EDGE_RAW / 3) mapped to 0..1

QUALITY_SCORE = mean(SAMPLE_SCORE, CLUSTER_SCORE, STABILITY_SCORE)

if EDGE_RAW <= 0: SNIPER_SCORE = EDGE_NORM × QUALITY_SCORE × 100
if EDGE_RAW > 0:  SNIPER_SCORE = ((EDGE_NORM + QUALITY_SCORE) / 2) × 100
```

**Alpha Executor:**
```
- Select top-5 by Sniper Score daily
- Allocate score-weighted per position
- Hold exactly 20 trading days
- Rebalance with chained equity (no reset to 100)
- Benchmark: SPY rebased to 100 at inception (2026-01-02)
```

## Parameter Experiment Workflow

When I ask you to **test a parameter combination**, follow this sequence:
1. Edit target parameters in `us_market/config/settings.py`
2. Run `us_market/pipeline/run_daily.py` (or specific stage scripts if partial run)
3. Check outputs in `us_market/output/` — specifically `sniper_summary.csv` and `equity_curve.csv`
4. Do NOT rebuild HTML unless I explicitly ask — focus on CSV/data outputs for speed

When I ask you to **debug a signal**, start with:
1. `us_market/analysis/single_sniper.py` for isolated ticker analysis
2. `us_market/engine/screen_score.py` for radar formula inspection
3. `us_market/engine/backtest_engine.py` for scoring logic
