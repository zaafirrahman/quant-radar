00 System Overview

Quant Radar implements a signal-first, statistics-driven pipeline to identify high-probability swing trading opportunities in the US stock market.

Instead of predicting markets, the system evaluates historical signal behavior to rank opportunities based on edge and signal quality — eliminating subjective bias.

CORE Design Principles
▶ Signal-first approach — evaluate signals, not predictions
▶ Edge + Reliability framework — profitability must be consistent
▶ Event-based backtesting — grounded in observable historical events
▶ Statistical filtering before ranking — no raw momentum shortcuts
▶ Momentum-driven swing opportunities — short to mid-term horizon

02 Radar Scanner
STEP 01 Market Screener — Momentum Candidates

Scans the entire stock universe and scores each ticker based on three compounding momentum conditions. Only structurally active, high-momentum assets pass through.

14-Day Price Momentum Volume Expansion 325-Day Range Position

Stocks are ranked by Distance % — how far the current signal score sits above its historical 95th percentile threshold. Only tickers with Distance > 0 advance to the Sniper Engine.

Output: Signal Surge Amplifier Grid
03 Sniper Validator
STEP 02 Sniper Engine — Signal Day Detection

For each candidate, the engine scans 3 years of historical data to detect every day the screener conditions were triggered above the threshold. These are called Signal Days — moments where the system would have generated a trade opportunity.

Output: Signal Day Dataset per Ticker
STEP 03 Backtest Layer — Edge Measurement

Each signal day is evaluated by measuring forward returns over three horizons. From these results, edge metrics are calculated per ticker.

5-Day Return 10-Day Return 20-Day Return Win Rate Avg Return Swing Score
Output: Runner Performance Protocol
STEP 04 Signal Quality Engine — Reliability Filtering

Not all profitable signals are reliable. This layer evaluates the statistical quality of the signal dataset using three independent drivers.

Sample Reliability

Measures whether the signal appears often enough to be statistically meaningful. Avoids signals based on too few observations and reduces random performance spikes.

Return Stability

Evaluates how consistent signal returns are across time. Detects whether profitability is stable or driven by rare outliers.

Cluster Distribution

Checks whether signals are spread across time or only appear during specific short market regimes. Prevents regime-dependent signals.

Output: Signal Quality Score
STEP 05 Final Ranking — Edge × Quality

The final ranking combines profitability and reliability into a single score, ensuring candidates are ranked on both expected return and signal robustness — not raw momentum alone.

Final Score = Edge × Quality
Output: Ranked Candidate List
